# REALM-Bench Evaluations

This directory stores benchmark evaluation artifacts.

Each evaluation should describe:

    problem id
    solution id
    constraint satisfaction
    objective value if available
    optimality status
    disruption handling result
    known limitations

## Current status

R6.4 only establishes the public repository layout and case reports.

Executable evaluations begin in later milestones, starting with Thanksgiving P6/P9.

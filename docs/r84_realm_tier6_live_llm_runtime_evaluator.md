# R84 REALM Tier-6 Live LLM Runtime Evaluator

## Purpose

R84 adds a deterministic runtime replay/evaluator layer for the R83.5c kernel trace records.

It reads the deterministic kernel trace report and evaluates each trace record for runtime-style consistency without mutating the production runtime store.

## Position in the Sequence

- R83.5a: manual live-LLM response packs
- R83.5b: deterministic comparison/import report
- R83.5c: deterministic kernel-admission trace attachment report
- R84: deterministic runtime replay/evaluator report

## Input

Default input:

- `results/realm_tier6_live_llm_manual/kernel_trace_report/kernel_trace_report.json`

This file is generated by:

    python benchmarks/realm/tier6_live_llm_kernel_trace.py trace

## Command

    python benchmarks/realm/tier6_live_llm_runtime_evaluator.py evaluate

Default output:

- `results/realm_tier6_live_llm_manual/runtime_evaluator_report/runtime_evaluator_report.json`
- `results/realm_tier6_live_llm_manual/runtime_evaluator_report/runtime_evaluator_report.md`

## Evaluator Checks

For each record, R84 checks:

- kernel method and admitted/rejected consistency
- high unsupported-specificity handling
- flagged-admission consistency
- deterministic timestamp use
- stable record ID presence

Globally, R84 checks:

- unique record IDs
- contiguous event ordering
- deterministic timestamps
- no nondeterministic `events.jsonl` output

## Runtime Mode

R84 uses:

- deterministic replay
- no runtime-store mutation
- no nondeterministic event emission
- stable JSON and Markdown output

## Claim Boundary

R84 phase 1 is a deterministic runtime replay/evaluator report.

It does not claim:

- API-automated LLM behavior
- production CTL-domain StateView realization
- confirmatory Chapter 6 evidence
- proof of AGI, wisdom, or autonomous scientific reasoning

Mnemosyne still owns admission. REALM still owns scoring.

A later R85 step should connect these runtime-evaluated records back into REALM Tier-6 scoring so the live-LLM packs can be compared by REALM metrics after Mnemosyne admission.

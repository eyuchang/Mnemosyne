# R86 REALM Tier-6 Live LLM Official Scorer Handoff

## Purpose

R86 exports the R85 Mnemosyne-side score bridge into a deterministic handoff bundle for official REALM Tier-6 scoring.

It does not run the official REALM scorer yet. It defines the stable input contract for the official scorer integration.

## Position in the Sequence

- R83.5a: manual live-LLM response packs
- R83.5b: deterministic comparison/import report
- R83.5c: deterministic kernel-admission trace attachment report
- R84: deterministic runtime replay/evaluator report
- R85: deterministic REALM score-bridge report
- R86: deterministic official-scorer handoff bundle

## Input

Default input:

- `results/realm_tier6_live_llm_manual/realm_score_bridge_report/realm_score_bridge_report.json`

This file is generated by:

    python benchmarks/realm/tier6_live_llm_realm_score_bridge.py score

## Command

    python benchmarks/realm/tier6_live_llm_realm_scorer_handoff.py export

Default output:

- `results/realm_tier6_live_llm_manual/realm_scorer_handoff/realm_scorer_handoff_bundle.json`
- `results/realm_tier6_live_llm_manual/realm_scorer_handoff/realm_scorer_handoff_cases.jsonl`
- `results/realm_tier6_live_llm_manual/realm_scorer_handoff/realm_scorer_handoff_report.md`

## Handoff Labels

R86 maps Mnemosyne-side admission states to REALM-facing scorer actions:

- `clean_admission` -> `score_admitted_proposal`
- `flagged_admission` -> `score_admitted_with_grounding_flags`
- `protective_rejection` -> `score_rejection_as_protective_screening`
- `unsafe_admission` -> `score_as_safety_failure`
- `rejected` -> `score_rejection`

## Claim Boundary

R86 phase 1 creates a deterministic official-scorer handoff bundle only.

It does not claim:

- official REALM scoring
- API-automated LLM behavior
- production CTL-domain StateView realization
- confirmatory Chapter 6 evidence
- proof of AGI, wisdom, or autonomous scientific reasoning

Mnemosyne still owns admission. REALM still owns scoring.

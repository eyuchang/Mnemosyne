# REALM-Bench Recovery Artifacts

This directory stores explicit recovery artifacts generated from executable benchmark runs.

For Thanksgiving P9, the recovery artifacts separate the lifecycle into:

    commitments
    wakeups
    repair proposals
    repair admissions
    audit lineage

These files are generated by:

    python benchmarks/realm/scripts/run_thanksgiving_recovery_trace.py

They are also checked by pytest so the committed artifacts remain reproducible.
